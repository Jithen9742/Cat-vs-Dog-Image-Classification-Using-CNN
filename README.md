This project develops a deep learning model to classify images of cats and dogs using Convolutional Neural Networks (CNNs). The dataset is preprocessed by resizing images to 15x15 pixels, normalizing them, and applying data augmentation techniques like zoom, rotation, and flipping. The CNN architecture consists of multiple convolutional layers (64, 128, 256, and 512 filters) with max pooling and Global Average Pooling for feature extraction. The model is compiled using the Adam optimizer and trained with sparse categorical cross-entropy loss. After training, the model achieves high accuracy in classifying unseen images. A custom function allows for real-time predictions on new images, making it a practical image classification tool.
